# Diabetes Prediction Assignment

This repository contains a notebook for the diabetes prediction assignment using machine learning.

## Files
- `diabetes_prediction_notebook.ipynb` — self-contained notebook with data exploration, preprocessing, model training, and evaluation
- `diabetes (1).csv` — dataset used for the prediction task

## Objective
Build a machine learning classification model to predict whether a patient is likely to have diabetes based on health-related features.

## Models compared
- Logistic Regression
- Random Forest
- Gradient Boosting

## Best performing model
Random Forest achieved the best test F1-score on the provided dataset.

## How to run
Open the notebook in VS Code or Jupyter and run the cells in order.
